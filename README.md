# EXY Global

Corporate website for EXY Global, a Nigerian company focused on human capacity development, professional training, hiring and consultancy.

## Pages

- Home
- About Us
- Services
- Contact Us

## Local development

1. Install Node.js 22 or later.
2. Run npm install.
3. Run npm run dev.
4. Open the local URL shown in the terminal.

## Production build

Run npm run build.

The website includes its EXY Global hero image, responsive navigation, styling, direct phone/email links and contact enquiry form.
